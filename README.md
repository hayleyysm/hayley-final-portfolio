# Hayley Simone Moonsamy Portfolio

Interactive Media portfolio website for exam submission.

## Pages

- `index.html` - home page and featured projects
- `projects.html` - project overview
- `project1.html` - Sonder Group case study
- `project2.html` - House of Malaika case study
- `project3.html` - Travel Talk Africa case study
- `about.html` - about page, personal reel, resume/referral links, and interactive bag
- `contact.html` - contact page with direct social and email links

## Run Locally

Open the folder in VS Code and use Live Server on `index.html`, or open `index.html` directly in a browser.

## Assets

Images, videos, PDFs, and social icons are stored in the asset folders and referenced with relative paths so the site can be deployed as a static website.
